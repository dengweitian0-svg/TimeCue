### 主要路径

- 正常确认：N01 → N04（保存中）→ N05（同刻下一条）→ N06 → N07（此前消息）→ N08 → N09（空）。
- 失败重试：N10 → N04 → N05。初始列表任意查看保持 3 条消息。
- 常规设置：G01 → G02（选择退出未保存）→ G03（保存成功）→ W03 → W04；隐藏偏好保存为 G04，关闭进入 W01。
- 日志目录：D01 → L01（选择；取消回 D01）→ L02 → L03 → L04；L05/L06 是失败评审场景。
- 备份目录：D01 → B01 → B02 → B03 → B04；B05/B06 是失败评审场景。
- 同刻通知：W06 逐条与 W07 汇总分别评审。汇总只进入单条详情。
- 平台异常：W05 → W08（残留通知点击，不承诺冷启动）；重试清理 → W03 → W04。

Figma 是场景原型，跨设置/通知等命名场景重新进入时按该场景数据重置；完整状态持久化、任意点击组合、异步交错以 React 自动测试和实际演示验证。异常状态页另设独立原型起点，便于逐个评审。
