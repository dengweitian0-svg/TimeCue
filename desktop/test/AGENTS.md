# 桌面测试

- `config_file_store_test.dart`：缺少用户文件、未知字段及注释保留、多实例并发、非法输入/文件错误后继续保存、大小写键兼容、恢复运行覆盖值和固定目录测试；检查 Go default.yaml 的字节保持不变。

- `widget_test.dart`：房间入口、本子页面、编辑弹层、焦点、动效与布局测试。
- `notebook_model_test.dart`：示例数据、提醒确认、分页选择和页面状态测试。
- `http_notebook_repository_test.dart`：HTTP 路径、快照、分页、确认、错误和刷新测试。
- HTTP 投递测试复用原 HttpServer 夹具，覆盖 health 根路径、三条同级通知 POST、JSON、完整 recovery 响应、不改变界面加载状态及矛盾回填/未知任务拒绝。
- `windows_notification_bridge_test.dart`：用可控 tick、Completer 和平台替身验证重复领取去重、start/结果丢响应、同批失败隔离、无需展示、明确失败及未知结果、健康失败/停止接纳/404/409、无断线换进程、停止与释放竞争、空领取无心跳，以及宿主可见错误和连接重试。平台替身测试不作为系统横幅真机证据。
- `notebook_time_picker_test.dart`：时间输入、转盘联动与交互测试。
- `notebook_loaded_status_test.dart`：已加载提醒详情显示待投递，不显示已提醒。
- `notification_query_test.dart`：复用原 HTTP 夹具验证 task/attempt 身份与游标、详情错配、真实双状态、恢复摘要与未知总数、未确认数兼容/校验、确认成功后刷新失败时作废旧计数并读取新剩余数、错误保留及查询不发布本子状态。
- `notification_view_model_test.dart`：冻结/历史查询隔离、旧运行拒绝、409 有界重读、400 游标废弃、断线原游标重试、轮次/摘要匹配和迟到响应失效；持久详情在运行失效后独立可读。
- `notification_reader_widget_test.dart`：验证房间/本子恢复入口、房间仅显示本轮明确正数未确认遗漏，确认后 2→1→0 且其他待确认不干扰、全确认启动不提示、sent 未确认仍提示、完成后继续刷新至确认归零、点击后同轮隐藏/新轮重新显示、就绪前点击缓冲、重复/新目标复用弹窗、草稿及选择保留、双状态与滚动、恢复空态及前后台轮询；替身点击不作为系统通知真机证据。

- HTTP 测试覆盖 201/204、PUT、草稿版本、暂停创建、多时间规则、结果不明时幂等重试、冲突保留与重新加载，以及管理列表包含暂停规则、恢复提交原 revision 和完整混合周期；`schedule_rules_test.dart` 验证预设往返和复杂规则保留，`schedule_management_test.dart` 从实际房间和今日日程本入口验证无未来投影的暂停日程仍能查看名称/说明/时间，打开独立修改弹窗而不打开本子或切换原页面；覆盖恢复未来安排、保存后列表刷新、未保存修改舍弃/继续、详情读取失败重试及删除后刷新。

日历计数测试覆盖：按日程身份去重、包含已确认/未确认、排除暂停与删除、零条显示“无日程”、未选日期使用今日、读取服务端完整总数且不随加载分页改变、失败保留快照。

日期对齐回归使用仅星期四带标记的月历，检查 2026 年 10 月和 11 月中，选中/未选中、有标记/无标记日期数字的同一行纵坐标一致。

- `schedule_editor_test.dart`：周期＋添加、星期/日号与时间同时选择、圆角项悬停删除、重复/混合类型拒绝、空列表校验及独立组合保存；每天/每周/每月点击时间框预填原值，取消保留，确认原位替换且不改变其它项，保存前不改仓储，重复或无效替换保留原草稿。

每月选择回归同时检查日号网格位于时间输入左侧，并验证选中 31 日及具体分钟后生成正确的周期时间项。
- `notebook_date_time_picker_test.dart`：单次唯一＋入口、选择后隐藏＋、点击已有框预填日期/时间并直接修改、取消保留、删除后恢复＋、左日历右时间、一次确认和取消、窄窗口横向访问。
- 时间选择器不再包含步进工具行；滚轮跨 59→00 仍可调整。规则转换回归验证同频率日期与时间配对无损，不把周一 09:00、周三 18:00 扩展成四次安排。

- historical_pending_test.dart：复用 HTTP 夹具，验证 0/50/51/125 条两范围完整分页、独立请求与迟到响应、位置/选择/提交隔离、确认失败及成功刷新失败、跨午夜分页重载、混合日期不发布、旧游标 400 重读、读取失败禁止过期今日提交与演示时钟。
- historical_pending_widget_test.dart：独立于网络测试的 Widget 夹具，验证三标签顺序、今日左右范围、历史日期分组、完整时间、四种真实状态及查看详情只读；Widget 绑定不用于 HTTP 服务测试。

- `desktop_lifecycle_test.dart`：关闭不释放、最新显隐意图、托盘不可用/恢复、隐藏未知结果、就绪回应与新目标竞争、登录意图、D6 冻结成员弹窗、退出监听重入、共享预算及迟到操作隔离、窗口失败后成功唤回清除提示、保留独立托盘错误及重试入口准确性；平台替身不冒充系统点击证据。
- [native](native/AGENTS.md)：独立 Windows 原生协议与进程测试，覆盖同时选主、真实 IPC、Unicode/非法输入、就绪前缓冲、重复 ACK、退出拒绝、2 秒超时及 abandoned mutex 恢复。编译启用 /W4 /WX，使用自有隐藏子进程和隔离锁名。

- `managed_backend_test.dart`：ready 分片/协议反证、健康错配、截止后不启动请求、显式重试、退出竞争、零预算最终回收、异常身份及迟到代次；`managed_repository_test.dart` 使用真实 HttpServer 验证握手前零业务请求、预期身份拒绝、退出关闭和失败重试；`managed_host_test.dart` 验证实际 Widget 门禁、隐藏意图下失败可见、托管桥身份隔离与在途平台结果不补交。
