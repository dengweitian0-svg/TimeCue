# 房间场景

展示随北京时间变化的房间，并提供日程本、添加日程、管理日程和左上角设置入口。设置打开独立弹窗，使用应用注入的配置文件存储，不依赖业务 HTTP 连接；未注入时禁用并提示演示模式不修改本地配置。管理入口独立于本子和日期投影，包含已暂停日程；选择规则后直接打开独立修改弹窗，保存或取消回到管理列表，不打开本子。连接不可用时仍可尝试读取管理列表并重试。

- `room_screen.dart`：主屏装配、入口焦点、本子显隐与前后台切换。
- 房间恢复卡片与本子入口读取同一仓储摘要；房间在前台且当前整理未完成、未确认遗漏尚未归零或数量未知时每五秒刷新；关闭本子继续观察，已完成且全部确认时停止。历史跳转请求打开原历史标签，已有编辑会话经本子的草稿守卫处理，不直接清空草稿。
- 点击房间恢复卡片打开记录后，本次房间运行内隐藏该 recoveryId 的提示，关闭详情及刷新同轮进度不再显示；新的恢复轮次重新显示。本子的恢复记录入口继续可用。
- 房间卡片显示本轮尚未确认的遗漏数量，来自服务端 unacknowledgedCount；完整遗漏未知、未确认数量未知或为零时隐藏。已确认记录不再触发提示，其他轮次/日程的待确认总数不参与估算；完整历史仍保留，卡片不使用整理数量或可投递数量。
- `room_backdrop.dart`：时段背景切换、图片淡入与窗玻璃遮罩。
- `room_clock.dart`：北京时间显示与前台恢复同步。
- `room_geometry.dart`：背景 cover 变换、窗区域和热区坐标计算。
- `desk_notebook_hotspot.dart`：桌面本子点击区域、可见裁切、键盘焦点与悬停提示；`Tooltip` 排除提示的语义文本，无障碍名称由按钮的 `Semantics` 提供。Windows AXTree 报错须通过完整重启后的交互验证定位，不能仅凭热更新后的日志判定原因。

工程约束：背景、窗玻璃遮罩与本子热区共用源图的 cover 变换；本子热区与视口求交，部分可见仍可点击，完全不可见才隐藏。环境时钟使用真实 UTC+8，与演示业务时间独立。添加入口接入真实 Go 创建；连接不可用时禁用写入入口，保留快照与重试。

房间将 `NotebookOperationFeedback` 映射到应用级操作 Toast；本子确认状态模型只经回调发布结果，不持有界面上下文。
