# 日程编辑界面

提供创建弹层、独立修改弹窗和日历右页共用的日程表单，默认写入 Go，保留显式内存演示。`ScheduleEditDialog` 接收已读取的完整规则及 revision，复用创建弹层的表单容器和舍弃守卫；保存/删除返回成功结果供管理列表刷新，取消保持原规则。Escape、系统返回和关闭按钮统一守卫未保存草稿，保存期间禁用关闭。

- `schedule_editor.dart`：名称、说明、类型、日期与周期预设，草稿校验、保存、删除及舍弃确认。
- `notebook_time_picker.dart`：小时/分钟原位输入、双圈小时转盘、分钟转盘、拖动、滚轮与键盘调整。

工程约束：计划时间为 UTC+8 分钟精度，秒和亚秒归零；时间输入与转盘同步，空值/越界值禁止确认。编辑已有日程不改变类型；已到期单次原触发时间只读，草稿与仓储快照不共享可变对象。更新保留编辑时的 revision，后台刷新不覆盖字段；版本冲突保留草稿并提供重新加载。保存/删除期间禁止导航及重复提交，失败保留输入。

周期表单通过“＋”逐项添加：每天选时间，每周选一个星期与时间，每月选一个日号与时间。ScheduleTimeSlot 独立保存日期/时间组合，不能把不同项的日期和时间交叉组合；重复项拒绝添加。存在时间项时锁定周期类型，删除全部项后才能切换；旧同频率多日 cron 可拆成可编辑项，混合频率原规则保留，只改名称、说明及启停。创建暂停规则仍原子提交。

已有暂停周期的详情表单提供“重新开启”按钮，启用后通过同一保存用例提交当前草稿及原 revision，保留名称、说明和时间规则。失败保留草稿与错误，保存期间禁止重复提交，服务不可写时禁用恢复；单次日程和已删除日程没有恢复按钮。

- `schedule_slot_picker.dart`：每天、星期/时间、日号/时间的单项选择弹层，日期与分钟时间一起确认。

每月弹层复用单次的左右布局：左侧 1–31 日号网格与短月说明，右侧时间输入/转盘；普通字号为七列日号，小窗口可横向访问，较大字号减少列数。取消/确定始终固定在底部。
- `schedule_time_chip.dart`：圆角时间项，点击或键盘激活打开对应选择器修改；悬停或键盘聚焦显示右侧 ×，点击 × 只移除草稿，不触发编辑、不弹删除确认，按钮空间预留避免悬停位移。
- `notebook_date_time_picker.dart`：单次合并弹层，左侧日历、右侧时间输入/转盘，一次确认提交日期与时间，取消不修改草稿；小窗口允许横向访问两侧，业务今天使用 UTC+8。

单次只允许一项：未选时显示＋，选中后只显示日期时间圆角框，删除后重新显示＋。未明确选择不能保存；已到期原触发只读。所有时间弹层移除“－／每格说明／＋”辅助行，输入、转盘、滚轮与键盘仍可调整；取消/确定固定在底部。

单次、每天、每周、每月均支持点击已有时间框直接修改，选择器预填该项当前日期/星期/日号及时间。确认只更新草稿中的该项并保留其它项与顺序，取消或值未变化不标记修改；周期重复或无效替换保留原项并提示错误。保存后才写入正式规则；保存期间、已删除规则及已到期单次原触发保持只读。
