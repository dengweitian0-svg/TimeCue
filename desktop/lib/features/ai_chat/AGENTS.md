# AI 对话界面

- `ai_chat_spread.dart`：日程本内嵌双页 AI 会话历史、消息、草稿输入、取消与重试界面。
- 双页界面展示新建守卫原因、提交/未知/停止待确认状态和错误；思考内容可折叠及选取，回复可选取并通过复制按钮复制。
- 消息与思考正文使用 `SelectionArea` 包裹 `Text`，保留选取能力且不嵌套独立文本滚动；每个 `ExpansionTile` 使用按会话及 run 区分的 `PageStorageKey`，展开状态与消息列表滚动偏移分开保存。
- `ai_chat_model.dart`：会话与草稿状态、最多三个活跃保留名额、原文及幂等键重试、流游标恢复、取消和生命周期失效状态。删除中的运行保留并发名额；随后收到并发上限拒绝时标记为明确可重试，保留原文及幂等键，不计为已创建或结果未知的运行名额。
- 只有没有选中会话或选中了已有 run 的会话且活跃保留名额未满 3 时，才能新建本地会话；按钮状态由 `canCreateSession` 和 `createSessionDisabledReason` 提供，`createSession()` 自身也实施相同守卫。当前空白草稿不会按标题判断或自动丢弃。
- 创建提交中或结果不明时拒绝删除会话，先等待提交结果，或使用原文和原幂等键重试以取得 run ID。已删除的运行会话隐藏消息但保留 SSE 监听；明确 end/204 并读取正式状态后释放名额，GET 404 本身不释放名额。
- 创建提交中、结果不明或会话停止待重试时锁定原始输入；会话停止待重试仅能重发原文和原幂等键，本地新会话可以直接删除。创建成功后会话按最新对话移到历史列表前部。SSE 重连后收到有效帧会清除瞬时连接错误，事件自身的业务错误继续显示。
- 界面读取和操作 `AiChatModel`；model 生命周期由外部管理，本组件只释放自身控制器。
- 历史消息与状态必须来自模型，不从自然语言生成结构化日程。
