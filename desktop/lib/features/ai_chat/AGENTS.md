# AI 对话界面

- `ai_chat_spread.dart`：日程本内嵌双页 AI 会话历史、消息、草稿输入、取消与重试界面。
- `ai_chat_model.dart`：会话与草稿状态、最多三个可见活跃会话、原文及幂等键重试、流游标恢复、取消和生命周期失效状态。删除中的运行保留并发名额；随后收到并发上限拒绝时标记为明确可重试，保留原文及幂等键，不计为已创建或结果未知的运行名额。
- 创建提交中、结果不明或会话停止待重试时锁定原始输入；会话停止待重试仅能重发原文和原幂等键，本地新会话可以直接删除。创建成功后会话按最新对话移到历史列表前部。SSE 重连后收到有效帧会清除瞬时连接错误，事件自身的业务错误继续显示。
- 界面读取和操作 `AiChatModel`；model 生命周期由外部管理，本组件只释放自身控制器。
- 历史消息与状态必须来自模型，不从自然语言生成结构化日程。
