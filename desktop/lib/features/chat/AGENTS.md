# 聊天功能

- `chat_view_model.dart`：由 `ChatGateway` 驱动的本地草稿与服务端历史索引、完整会话名称、正式回复摘要、运行与阅读状态、删除墓碑、SSE 游标、工具调用、有限重连及并发占用；删除当前会话后选中新空本地会话，删除响应不明时仅在历史详情明确返回 session_not_found 后完成墓碑清理；历史刷新同时核验服务端列表外的待确认删除会话，与列表去重并共用有界并发及进度，暂时读取失败继续保留；索引状态独立通知，状态独立于 Widget 生命周期。
- `chat_session_list.dart`：历史会话展示名称/摘要搜索（空服务端名称使用“未命名会话”展示名称参与搜索，服务端原值不变）、索引进度、日期分组、读取失败重试和删除确认；本地会话区分显示未发送草稿与创建中/结果待确认的请求，并保留请求会话的下一条草稿；小高度或大字模式下页头可滚动、结果列表保留访问空间；只监听历史元数据通知，不因 SSE 正文增量重建历史列表。
- `chat_composer.dart`：受限高度的单会话输入、Enter/Shift+Enter、输入法组合保护、发送及停止入口；运行时仍可编辑下一条草稿。
- `chat_message_list.dart`：可选择的用户输入、独立过程状态、淡纸助手正文、内联错误和滚动消息；上读不抢滚动并提供回到最新。
- `chat_markdown_body.dart`：使用固定版本 `gpt_markdown 1.3.4` 渲染累计原始正文；流式代码通过包内 `CodeField` 暂缓语法高亮，终态恢复默认代码渲染，缓存包含流式状态；保留代码/表格块内横向访问、文字缩放、代码和链接复制及系统浏览器入口；限制标题层级、正文行高并缓存未变化的 Markdown 子组件。
- `chat_tool_call_list.dart`：以开始事件 seq 与原工具 ID 区分展示实例，折叠显示完整名称、原 ID、参数、原始 JSON 结果和错误；开始记录不证明业务已生效，结果只与当前尚未完成的同 ID 请求配对。
- `chat_event_timeline.dart`：按原始事件顺序提供完整记录及按需续页，思考与 JSON 详情默认折叠；控制事件参与消费，不通过 seq 或文本猜测模型轮次、续写和恢复尝试边界。

真实模式下由应用宿主持有模型并注入页面；页面卸载、切换标签或合上本子不释放 run 连接。窗口隐藏时可抑制界面通知但继续处理事件，恢复展示时发布累计状态。宿主退出或后端运行身份失效时停止新操作、隔离当前代次并释放传输。

run 的终态由 finished_at、最终 end 或真正终态回执确认后单向进入；SSE 204 停止重连并读取概况和完整缺失事件。cancelled 且 finished_at=null 表示取消收尾中，继续订阅并占用名额；cancelled 创建回执须查询概况。创建结果不明时保留原输入、模型及幂等键占位供安全重试，不自动以新键创建第二轮。聊天不访问数据库，服务端使用真实模型和 SQLite。

204 已确认结束时即释放运行占用；概况与历史同时读取失败仍保留独立的读取重试，不重新订阅或伪造成功/失败状态，具体结果未知时显示记录恢复阶段。

分页与 SSE 共用每个运行的串行事件应用队列，以 (run_id, seq) 去重并先补缺口；成功应用后才推进消费位置，不直接采用 next_after_seq。原始时间线与 run.output 正文投影分别保存；终态概况不会覆盖时间线，历史事件不会重复追加到终态正文。展示状态由宿主持有，新 ViewModel 从零消费，不保存脱离历史内容的孤立游标。

历史刷新先取得已有活跃运行的终态时，关闭订阅后仍经同一事件队列补齐持久化尾部；此前读到的空页或 has_more=false 不阻止这次恢复。

## 约束

- ViewModel 只依赖聊天契约，不访问 HTTP 细节、SQLite 或 Widget。
- run 的服务端终态与连接、创建和取消过程分开表达；断线及取消受理不释放并发名额。
- 修改本模块组成、功能或约束时同步本文件。

- ViewModel 读取及刷新模型列表，以 provider/model 组合选择本地可用选项；创建和重试固定该身份。终态创建重放直接恢复 output/error，不再订阅 SSE；独立 error 不自行确认运行终态。
