# 聊天功能

- `chat_view_model.dart`：由 `ChatGateway` 驱动的本地草稿与服务端历史索引、完整会话名称、正式回复摘要、运行与阅读状态、删除墓碑、SSE 游标、工具调用、有限重连及并发占用；历史读取有界并发，索引状态独立通知，状态独立于 Widget 生命周期。
- `chat_session_list.dart`：历史会话名称/摘要搜索、索引进度、日期分组、读取失败重试和删除确认；小高度或大字模式下页头可滚动、结果列表保留访问空间；只监听历史元数据通知，不因 SSE 正文增量重建历史列表。
- `chat_composer.dart`：受限高度的单会话输入、Enter/Shift+Enter、输入法组合保护、发送及停止入口；运行时仍可编辑下一条草稿。
- `chat_message_list.dart`：可选择的用户输入、独立过程状态、淡纸助手正文、内联错误和滚动消息；上读不抢滚动并提供回到最新。
- `chat_markdown_body.dart`：使用固定版本 `gpt_markdown 1.3.4` 渲染累计原始正文；流式代码通过包内 `CodeField` 暂缓语法高亮，终态恢复默认代码渲染，缓存包含流式状态；保留代码/表格块内横向访问、文字缩放、代码和链接复制及系统浏览器入口；限制标题层级、正文行高并缓存未变化的 Markdown 子组件。
- `chat_tool_call_list.dart`：按所属 run 的独立调用身份显示完整工具名称和稳定编号，只标识已发起，不推断单工具结果或执行关系。

真实模式下由应用宿主持有模型并注入页面；页面卸载、切换标签或合上本子不释放 run 连接。窗口隐藏时可抑制界面通知但继续处理事件，恢复展示时发布累计状态。宿主退出或后端运行身份失效时停止新操作、隔离当前代次并释放传输。

run 的终态只能由服务端快照确认后单向进入；创建结果不明时保留原输入、模型及幂等键占位供安全重试，不自动以新键创建第二轮。聊天不访问数据库，当前服务端仍是内存 Mock。

## 约束

- ViewModel 只依赖聊天契约，不访问 HTTP 细节、SQLite 或 Widget。
- run 的服务端终态与连接、创建和取消过程分开表达；断线及取消受理不释放并发名额。
- 修改本模块组成、功能或约束时同步本文件。
