# 设置界面

- `settings_dialog.dart`：独立设置弹窗，读取并编辑日志级别、日志目录与数据库目录，提供保存、恢复默认、读取重试及未保存修改关闭守卫；拥有并释放本弹窗的软件更新控制器。数据库目录由文件存储自动补齐 timecue.db；已有配置读取为所属目录，未修改时保留原数据库文件名。内容可滚动，使用应用纸张主题。
- `software_update_section.dart`：显示当前/最新版本、发行说明、检查/下载状态与进度；external 仍可检查版本，但不能安装；重复操作期间禁用按钮。

约束：由应用入口注入与 Go 共用数据目录的 ConfigFileStore，只提交改变的覆盖字段；缺少覆盖值显示使用默认配置，不读取或复制 Go 内嵌默认基线。加载及写入期间禁止编辑与关闭，失败保留草稿。恢复默认需确认，只移除运行覆盖字段。路径保存提示下次启动应用及不搬迁已有数据，不切换运行连接。演示模式不接入真实文件存储。安装前明确确认重启；设置草稿先经现有舍弃确认，更新校验及 installer ready/commit/cancel 握手完成后才请求宿主退出。

主动读取、字段校验、保存及恢复默认的结果由应用 Toast 提醒；设置弹窗继续保留详细内联错误，以及成功后的路径生效说明。
