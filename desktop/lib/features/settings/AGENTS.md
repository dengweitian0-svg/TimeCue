# 设置界面

- 连接名称独立编辑并参与草稿守卫；已有 provider 只读，预设切换不修改已有身份。新建连接默认按现存 provider 的规范化名称分配 deepseek、deepseek_2 等独立身份，仍可在首次保存前填写其他身份；保存沿用全局密钥名冲突校验。保存后更新宿主名称映射，不重建聊天模型。

- 模型配置重开只展示逐模型的本地密钥配置状态，不向页面传递原 Key；状态不证明上游认证，新建或改名目标在保存时按目标身份核对密钥。草稿按连接名称、provider、服务地址、模型原身份、ID、预算及新 Key 与最近读取/保存的快照比较；关闭与 Escape 共用舍弃确认，撤回修改或保存成功后不再确认。读取、保存及应用期间禁用表单和关闭；卸载后不继续应用、不提示成功，延后关闭只作用于原路由。标题与内容共同滚动，支持小窗口和大字模式。

- 模型弹窗读取失败提供重试且禁用保存；保存失败保留模型及 Key 草稿，只展示存储明确提供的安全错误，其他解析/文件错误统一提示检查格式与权限。密钥恢复失败单独反馈；已保存待加载与未保存分开，运行失效或加载超时后恢复关闭及重试，不因关闭提示应用成功。

模型弹窗的校验、读取失败、保存失败及本地加载结果复用应用 Toast，并保留内联状态；已保存但尚未确认加载使用警告。

- `model_config_dialog.dart`：通用 Chat Completions 连接弹窗，支持 DeepSeek 预设与自定义；新连接 provider 与服务地址可编辑，已保存 provider 固定且名称可修改，模型 ID 手动填写。默认打开当前所选模型的连接，可选择已有分组或新建连接；切换前共用未保存草稿确认。保存仅更新目标分组，保留旧模型身份、其他连接和未知字段；Key 默认隐藏且可显隐，重开不回显；一次新 Key 用于全部目标模型，留空保留已有本地条目，缺少条目时拒绝保存。各模型独立编辑 ID 和预算，至少保留一项；失败保留输入。上下文/输出预算初值 32768/8192，放在高级设置中。读取、保存及自动加载期间禁止编辑、关闭和重复提交；校验失败不写文件，读写错误不回显密钥或配置原文。每次保存均调用当前 ChatViewModel 的完整目标集合有界刷新，已保存但未加载时允许只重试加载；本地可用提示不宣称认证成功。

- `settings_dialog.dart`：独立设置弹窗，读取并编辑日志级别、日志目录与数据库目录，提供保存、恢复默认、读取重试及未保存修改关闭守卫。目录字段通过 Windows 原生选择器选择；数据库目录由文件存储自动补齐 `timecue.db`，已有配置显示所属目录，未修改时保留原数据库文件名。已有相对目录按配置文件所在数据目录显示为绝对路径，未修改时保留原配置值。内容可滚动，使用应用纸张主题。

约束：由应用入口注入与 Go 共用数据目录的 ConfigFileStore，只提交改变的覆盖字段；缺少覆盖值显示使用默认配置，不读取或复制 Go 内嵌默认基线。加载、目录选择及写入期间禁止编辑与关闭，选择取消保留草稿，失败显示内联错误。恢复默认需确认，只移除运行覆盖字段。路径保存提示下次启动应用及不搬迁已有数据，不切换运行连接。演示模式不接入真实文件存储。

主动读取、字段校验、保存及恢复默认的结果由应用 Toast 提醒；设置弹窗继续保留详细内联错误，以及成功后的路径生效说明。
