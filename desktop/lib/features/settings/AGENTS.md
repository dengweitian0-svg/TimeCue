# 设置界面

模型弹窗的校验、读取失败、保存失败及本地加载结果复用应用 Toast，并保留内联状态；已保存但尚未确认加载使用警告。

- `model_config_dialog.dart`：独立的单模型 DeepSeek 配置弹窗，固定 provider 和官方地址；Key 默认隐藏且可显隐，重开不回显，每次保存需填写 Key。上下文/输出预算初值 32768/8192，放在高级设置中。读取、保存及自动加载期间禁止编辑、关闭和重复提交；校验失败不写文件，读写错误不回显密钥或配置原文。每次保存均调用当前 ChatViewModel 的有界刷新，已保存但未加载时允许只重试加载；本地可用提示不宣称认证成功。

- `settings_dialog.dart`：独立设置弹窗，读取并编辑日志级别、日志目录与数据库目录，提供保存、恢复默认、读取重试及未保存修改关闭守卫。目录字段通过 Windows 原生选择器选择；数据库目录由文件存储自动补齐 `timecue.db`，已有配置显示所属目录，未修改时保留原数据库文件名。已有相对目录按配置文件所在数据目录显示为绝对路径，未修改时保留原配置值。内容可滚动，使用应用纸张主题。

约束：由应用入口注入与 Go 共用数据目录的 ConfigFileStore，只提交改变的覆盖字段；缺少覆盖值显示使用默认配置，不读取或复制 Go 内嵌默认基线。加载、目录选择及写入期间禁止编辑与关闭，选择取消保留草稿，失败显示内联错误。恢复默认需确认，只移除运行覆盖字段。路径保存提示下次启动应用及不搬迁已有数据，不切换运行连接。演示模式不接入真实文件存储。

主动读取、字段校验、保存及恢复默认的结果由应用 Toast 提醒；设置弹窗继续保留详细内联错误，以及成功后的路径生效说明。
