# 日程本

提供双页日程浏览、提醒确认、日历导航和 AI 对话页面框架。

- `notebook_view_model.dart`：标签、月份、日期右页、详情/编辑导航、加载与错误、查询轮询、分页及跨页提醒选择状态；另保存 AI 页面导航位置和运行内输入草稿。
- `notebook_spreads.dart`：今日安排、待确认列表与批量确认、月历、日期清单、详情和本子框架组件；loaded 与 pending 均显示待投递，不伪装为已提醒。AI 标签内容由 `chat_spread.dart` 提供双页欢迎与单栏历史导航框架；发送和历史查询未开放时保持禁用。
- `notebook_overlay.dart`：本子开合动画、遮罩、焦点、Escape、编辑草稿舍弃及历史标签跳转请求；外部跳转同样守卫未保存草稿。
- `notification_view_model.dart`：通知激活及恢复历史的独立只读分页、身份核验、过期提示、详情和异步代次；续页 409 有界重读首页，400 废弃旧游标，错误不替换为待确认查询。运行失效后已知持久提醒 ID 仍可独立读详情。
- `notification_reader_dialog.dart`：本次展示成员/本轮历史的单一只读弹窗，单条 minute 直接显示详情；前台五秒刷新当前成员页，后台及关闭停止普通查询，返回前台重读首页。点击、查看、翻页和刷新不确认或重新展示。
- `notification_details.dart`：完整内容与原计划时间、真实投递及确认状态独立展示，HTTP 详情刷新失败保留原内容并提示；长内容可滚动。
- `recovery_status.dart`：恢复摘要及三种整理状态、完整历史/未确认/可投递的独立数量、未知遗漏总数与固定上界文案；整理完成不代表投递或用户完成。

工程约束：全选仅捕获当前页明确提醒 ID，跨页选择保留，刷新不扩大选择，提交冻结选择；确认与投递结果独立且不提供撤销。旧请求按代次失效，加载/失败保留旧内容；本子关闭或进入后台停止普通轮询，恢复前台立即查询。开合中禁用本子交互，退出编辑前守卫未保存草稿。真实编辑先异步读取完整规则及 revision，过期的详情响应不能打开错误的编辑会话；不可编辑的历史只显示触发详情。

- `schedule_management_dialog.dart`：普通规则列表分页入口，包含已暂停日程及其名称、说明、时间规则和状态，点击后异步读取完整规则及 revision，打开独立修改弹窗；保存、恢复或删除成功后刷新当前分页，取消返回原列表，读取失败保留列表并允许重试。恢复入口不依赖日历投影。日程本书封固定提供管理入口，今日页和日历页均可使用；管理操作不切换本子页面、不舍弃本子原有草稿，原编辑保存期间禁止打开管理。

日历底部显示选中日期的实际启用日程数，尚未选日期时使用今天。零条显示“无日程”，否则显示“当日共 N 个日程”。按日程 ID 去重，包含已确认和未确认，排除暂停、删除、取消；加载或失败不能伪装为空。实心底色仍只表示选中日期。

日期格统一保留安排小点的布局高度，没有安排时只隐藏标记绘制，避免带标记的日期数字与同一行其它日期错位。选中背景和今日边框不改变数字对齐。

日程本标签依次为今天、历史待确认、日历、AI 对话。TodaySpread 左页保留今日全部安排，右页读取今日到期未确认；HistorySpread 按原计划完整日期分组，PendingList 共用真实状态、只读详情、选择、确认及分页。AI 内容在宽屏以双页展示，在窄窗口或大字模式下以单栏提供历史导航；发送与历史查询尚未开放。两个待确认范围分别保存位置、勾选和确认错误，提交冻结原范围 ID 与选择集合，最多 500 条；切换标签不混合提交。成功发布新北京日期时清空两范围选择和分页，新历史记录不自动勾选；失败读取保留原快照和选择。开合、草稿守卫及前后台轮询沿用原入口。

主动确认通过 `NotebookOperationFeedback` 窄回调向房间报告成功、失败、刷新警告和超量校验结果；ViewModel 不依赖 BuildContext 或 Widget。后台轮询、无操作及选择变化不产生 Toast。管理列表主动读取/编辑错误及写入后的列表刷新失败使用应用 Toast，同时保留窗口内联错误。
