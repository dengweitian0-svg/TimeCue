# 日程本

提供双页日程浏览、提醒确认与日历导航。

- `notebook_view_model.dart`：标签、月份、日期右页、详情/编辑导航、加载与错误、查询轮询、分页及跨页提醒选择状态。
- `notebook_spreads.dart`：今日安排、待确认列表与批量确认、月历、日期清单、详情和本子框架组件。
- `notebook_overlay.dart`：本子开合动画、遮罩、焦点、Escape 与编辑草稿舍弃交互。

工程约束：全选仅捕获当前页明确提醒 ID，跨页选择保留，刷新不扩大选择，提交冻结选择；确认与投递结果独立且不提供撤销。旧请求按代次失效，加载/失败保留旧内容；本子关闭或进入后台停止普通轮询，恢复前台立即查询。开合中禁用本子交互，退出编辑前守卫未保存草稿。真实编辑先异步读取完整规则及 revision，过期的详情响应不能打开错误的编辑会话；不可编辑的历史只显示触发详情。

- `schedule_management_dialog.dart`：普通规则列表分页入口，包含已暂停日程及其名称、说明、时间规则和状态，点击后异步读取完整规则及 revision，打开独立修改弹窗；保存、恢复或删除成功后刷新当前分页，取消返回原列表，读取失败保留列表并允许重试。恢复入口不依赖日历投影。日程本书封固定提供管理入口，今日页和日历页均可使用；管理操作不切换本子页面、不舍弃本子原有草稿，原编辑保存期间禁止打开管理。

日历底部显示选中日期的实际启用日程数，尚未选日期时使用今天。零条显示“无日程”，否则显示“当日共 N 个日程”。按日程 ID 去重，包含已确认和未确认，排除暂停、删除、取消；加载或失败不能伪装为空。实心底色仍只表示选中日期。

日期格统一保留安排小点的布局高度，没有安排时只隐藏标记绘制，避免带标记的日期数字与同一行其它日期错位。选中背景和今日边框不改变数字对齐。
