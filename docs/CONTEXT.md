# TimeCue

TimeCue 帮助用户管理日程与提醒，并提供围绕日程的对话协助。

## Language

**日程助手（Agent）**：
通过对话理解用户意图、回答问题，并借助日程工具查询、创建和修改日程的助手。
_Avoid_: 纯聊天机器人（无法完整表达其日程操作能力）

**会话（session）**：
组织多轮日程助手对话的历史集合，一段会话可以包含多次对话运行。

**会话历史**：
会话中保留的原始用户输入、助手输出及工具处理事实。摘要和上下文裁剪不会替换或删除这些原始记录。

**有效模型上下文**：
供日程助手当前模型交互使用的对话内容，由当前有效摘要及尚未被其覆盖的消息构成；尚无有效摘要时使用全部适用消息。它是会话历史的选取与压缩表达，不等于完整会话历史。

**会话摘要**：
对当前会话全部有效历史的压缩描述，可包含尚未结束的对话运行中已经完成的模型与工具交互。生效摘要与尚未被覆盖的消息共同构成后续有效模型上下文，已覆盖原文仍属于会话历史，但不重复进入模型上下文。

**摘要事件（compact）**：
会话中一次摘要需求发生的记录，每次需要进行摘要时记录一次，不随同一次模型调用的重试重复记录。记录该事件不代表摘要已生效；摘要失败时保留事件，原有有效摘要及历史分界继续有效。
_Avoid_: 摘要成功事件（不能表达摘要需求发生时即记录的含义）

**对话运行（run）**：
从一条用户输入开始，到助手最终回复或失败、取消结束的一次完整处理过程。其间可以包含多次模型调用和工具调用。
_Avoid_: 一次模型请求（不能表达完整的处理过程）

**相对时间解析**：
将“今天”“明天”等相对时间表达转换为明确时间的过程，以实际解析时的当前北京时间为基准。已经形成的明确时间和业务执行事实保留原含义。

**错误事件（error）**：
模型交互或对话运行自身发生一次错误的记录，用于向用户反馈这些错误。工具处理的失败信息通过对应的工具结果反馈；记录错误本身不代表整个对话运行已经结束。

**部分回复**：
对话运行失败或取消前，日程助手已经输出但尚未完成的内容，包括仅有思考内容而尚无正文的情况。后续对话保留已有内容及其未完成事实，回复中的操作表述不构成日程操作已经生效的证明。

**协作式取消**：
停止对话运行的后续推进，并保留已经接收的模型内容和已经开始处理的工具结果。进行中的模型交互可以终止；已经开始的工具操作须等待完成或超时后才完成取消。接受取消请求不等于运行已经结束。

**模型调用（model_call）**：
日程助手向模型提交上下文并尝试获取回复的一次逻辑交互，包含该步骤内的请求重试，是对话运行中的一个环节。未收到响应或调用失败，也属于需要保留的模型调用行为。
_Avoid_: 对话运行（run）

**续写（continuation）**：
为继续此前因长度限制而未完成的输出所进行的新一次模型交互，区别于重新生成摘要或重试原请求。续写延续被截断的思考或正文；工具调用被截断时，向用户和模型保留原调用事实但不执行，采用新回复中的完整调用。
_Avoid_: 再次摘要、请求重试

**模型工具调用标识（tool_call_id）**：
模型为一条工具调用返回的配对标识，在同一次模型回复内区分调用及其结果，不是跨模型调用的全局身份。参数被截断不会使该标识作废，解析异常仍通过原标识反馈；模型后续重新生成的调用使用该次回复实际返回的标识。
_Avoid_: tool_id（统一使用 tool_call_id，区别于工具名称）

**工具调用（tool_call）**：
一次模型工具请求的处理过程，包含参数解析、校验及后续操作。参数被截断、解析或校验失败也属于已处理但失败的工具调用，不表示已执行业务操作；日程操作是否生效以实际业务结果为准。

**工具开始事件（tool_start）**：
工具请求的开始侧记录，描述本次调用的身份、工具和参数，包括未开始便取消跳过的请求。该记录本身不证明工具已经开始处理或业务已经生效，实际处理及结果由调用状态和结果表达。

**工具结果事件（tool_result）**：
向用户提供某次工具调用原始结果、失败信息或取消跳过事实的记录，沿用该请求的模型工具调用标识，使调用与结果准确对应。取消跳过的记录不表示工具已经执行业务操作。

**中止结果（aborted）**：
工具请求因取消而不再继续处理时，反馈给模型的中止说明，沿用原调用标识维持请求与结果配对；不表示业务操作已经执行。

**危险工具（dangerous）**：
日程助手中使用幂等身份保护重复执行的工具类别，当前仅包含删除日程。
_Avoid_: 写工具（当前创建、修改日程也属于写操作，但不属于危险工具）
