# TimeCue 前端设计规范

本文提取当前 Flutter Windows 前端的视觉语言、组件样式及交互规则，供后续界面扩展使用。整理日期：2026-10-14。

以 `desktop/lib` 源码和房间资源为准，本地 `desktop/build/visuals` 截图仅辅助观察，不作为当前版本的验收证据。文中的「现状」表示已有实现，「建议」表示尚需收敛或验证；本文不代表相关界面改造已经完成。尺寸与字号均为 Flutter 逻辑单位，透明度与物理像素另行注明。

## 1. 统一视觉风格

**整体关键词：温暖、治愈、安静、日常、纸质、轻拟物。**

- 房间采用日系动画插画：木质家具、书籍、绿植、猫与自然光构成生活场景；背景承担氛围，前景控件保持简洁。
- 日程本采用暖棕封面、米色双页、书脊明暗渐变、纸面细分隔线和书签式标签；用少量立体效果表达「打开一本本子」。
- 功能层使用 Material 3 按钮、表单和弹窗，并通过纸张与暖棕主题保持一致；正文清晰，标题保留书页气质。
- 房间设置、日程本、管理和添加入口统一使用米白底、暖棕图标文字及 12 圆角；猫咪只添加透明交互热区，保留原图。
- 文案温和、短句、贴近日常，例如「添一件小事」「留一点时间，给日常」。错误与不可恢复操作明确说明结果，避免用氛围文案掩盖问题。
- 装饰保持克制：页面依靠留白、细线和颜色区分信息；完成事实用鼠尾草绿和勾选图标表达。

背景按北京时间切换：06:00–11:59 为早晨，12:00–17:59 为午后，其余为夜晚。夜景是场景变化，当前应用仍使用同一套浅色纸面主题，未配置独立深色主题。

## 2. 统一基础规范

### 2.1 颜色

核心颜色定义于 [`NotebookTheme`](../desktop/lib/theme/notebook_theme.dart)。下表用十六进制方便设计对照；Dart 自定义颜色遵循模块约束，使用十进制 `Color.fromARGB`。

| 名称 | 色值 | 当前用途 |
| --- | --- | --- |
| `paper` | `#FBF6E7` | 纸面、弹窗、Scaffold 背景；主按钮前景 |
| `ink` | `#594733` | 主要文字、日程名称、纸面前景 |
| `muted` | `#8B7964` | 说明、日期、时间、辅助标签、普通输入框描边 |
| `sage` | `#647750` | 已完成日程、完成图标、全部确认后的提示 |
| `line` | `#DED4BC` | 分隔线、容器配色、时间输入激活底色 |
| `cover` | `#91744F` | 封面、主操作、选中日期、输入焦点和光标 |

`ColorScheme` 以 `cover` 为种子；primary、secondary 均显式使用暖棕，两个 container 均使用 `line`。其余未覆盖的角色色由 Material 3 生成，错误色读取 `colorScheme.error`，未单独固定色值。

| 辅助颜色 | 当前用途 |
| --- | --- |
| `#F2EBDA` | `surfaceContainerHighest`、时间盘与未激活时间输入底色 |
| `#FFFAF0`、`#E5DCC6` | 纸面亮部和书脊暗部；左右页镜像渐变 |
| `#DBCAAE` | 未选中的本子标签底色 |
| `#FFFCF5` | 操作 Toast 底色 |
| `#56744D`、`#9A6B25` | Toast 成功、警告图标；成功色与 `sage` 目前分开定义 |
| `paper` / `ink` | 房间固定入口背景 / 图标文字 |
| `#FFF9ED`，不透明 | 房间时钟文字 |
| `#EEDEBE` / `ink` | 房间「添加日程」禁用背景 / 前景 |

使用规则：暖棕表示操作与选择，鼠尾草绿表示完成事实；错误使用主题错误色，并附文字。背景插画中的蓝、绿等色彩属于场景资源，不作为新增业务控件的强调色。建议后续将辅助色集中到主题，避免同类反馈继续出现不同色值。

### 2.2 字体与字号

全局字体为 `Microsoft YaHei`，回退顺序为 `Segoe UI`、`SimSun`；页面大标题显式使用 `SimSun`，日程行的时间使用 `Georgia`。当前未随应用打包字体，依赖系统字体。

| 信息层级 | 当前字号与样式 | 用途 |
| --- | --- | --- |
| 环境时钟 | 46，w300，字距 6 | 房间中心时间 |
| 时间输入 | 42，微软雅黑 | 小时、分钟数字；分隔冒号 38 |
| 页面主标题 | 28，宋体 | `titleLarge`、`PageHeading`、编辑和时间弹窗标题 |
| 日历月标题 / 历史日期分组 | 20 / 18，宋体 | 月份导航、历史分组 |
| 选择器分区标题 / 时间盘普通数字 | 16 | 选择日期、选择时间、刻度数字 |
| 默认正文 | 14，`ink` | 显式配置的 `bodyMedium` |
| 说明与辅助信息 | 12 / 11，通常为 `muted` | 副标题、状态、提示、封面操作 |
| 英文眉题 / 页码 | 10，字距 2.4 / 2 | 页头装饰标签、页码 |
| 时间盘选中数字 | 21，w700，下划线 | 与普通 16、w400 数字区分 |

现状：仅 `bodyMedium` 与 `titleLarge` 在全局 `TextTheme` 显式定义，其他文本角色和部分弹窗标题继承 Material 3 默认值；尚无完整的字号、字重、行高令牌。页尾温和提示使用 12 号宋体、1.8 行高，不能视作全局正文行高。

建议：新增同用途文字优先复用上述层级；关键说明保持正文级可读性，10–11 号字用于少量辅助信息。后续统一弹窗标题、正文行高与字重，并保留系统文字缩放，不通过缩小字号解决拥挤。

### 2.3 间距与密度

| 区域 | 当前固定值 |
| --- | --- |
| 纸页内边距 | 左 30、上 34、右 30、下 30 |
| 页头节奏 | 眉题后 12、标题后 8、副标题后 24、分隔线后 12 |
| 日程行 | 最小高度 66，上下内边距 16，时间列宽 62 |
| 房间固定入口 | 上 / 左 / 右通常 24；底部操作右 28、下 24；按钮间距 12 |
| 普通输入框 | 内容内边距 12 |
| 编辑弹窗 | 内边距 28，标题说明后 24，普通字段间距 18 |
| 时间弹窗 | 内容内边距 24/24/24/16，操作区 24/0/24/20 |
| 待确认工具栏 | 横向与换行间距均为 8 |
| 设置表单 | 分区间距 24，字段间距 20 |

现状：间距多为局部常量，没有共享间距类。建议新增常规布局优先使用 `4、8、12、16、20、24、28、32`；30/34 的纸页留白和 18 的编辑字段间距属于已有场景值，统一时成组调整，避免只改一处。

### 2.4 圆角、边框与阴影

| 对象 | 当前规则 |
| --- | --- |
| 普通 Dialog 与日期弹窗 | 圆角 7，暖棕边框宽 5；透明 surface tint |
| 本子封面 / 内页裁切 | 圆角 8 / 3 |
| 时间数字输入块 | 圆角 6，以底色区分激活状态 |
| 时间标签 | 圆角 24，暖棕边框宽 1；聚焦时 1.5 |
| 房间入口 | 圆角 12，最小高度 44，无边框 |
| 日历日期 | 圆形；今天暖棕描边，选中暖棕填充、米色数字 |
| 本子标签 | 上方圆角 7；选中纸色，未选中浅棕 |
| Toast / 房间恢复提示 / 宿主错误卡 | 圆角 12 / 12 / 8 |
| 本子投影 | 深棕 `ARGB(128,48,32,21)`，模糊 70，偏移 `(0,25)` |
| Toast / 宿主错误卡 | Material elevation 8 / 4；Toast 阴影 `black26` |
| 房间时钟 | 文字阴影 `black45`，模糊 12 |

纸页用亮—纸色—暗的镜像渐变表达书脊，左页 stops 为 `0/.945/1`，右页为 `0/.055/1`。本子遮罩最大黑色透明度 0.28、背景模糊 4；窗玻璃局部模糊 1.6。普通弹窗使用 Material 路由遮罩与过渡，尚未统一自定义参数。

建议：阴影用于表达浮起或遮挡关系，普通列表继续使用细线。默认按钮形状、输入框圆角与部分 Material elevation 仍由框架提供，不能宣称全局均已固定。

## 3. 统一组件样式

| 组件 | 当前样式与使用规则 |
| --- | --- |
| 主 Button | `FilledButton`：暖棕底、米色前景；用于保存、确定、确认选中 |
| 次 Button | `OutlinedButton`：暖棕前景、`muted` 描边；用于单条确认、时间添加等辅助操作 |
| 文字 Button | `TextButton`：暖棕前景；用于返回、取消、清空、重试、导航 |
| 房间 Button | 图标加文字，17 号图标、米白底与暖棕字、圆角 12、最小高度 44；设置、日程本、管理和添加共享主题样式 |
| IconButton | 常见图标为 16–20；关闭、分页、月份切换等提供 Tooltip；时间添加入口显式最小 44×44 |
| Input | Material 描边输入框；普通边框 `muted`，焦点边框 `cover`、宽 2；标签由 muted 切换为暖棕 |
| 文本选择 | 暖棕光标和选择柄；选区为暖棕 alpha 64/255 |
| Dropdown | 与输入框共享 `InputDecorationTheme`；日程类型、日志级别保持相同表单语言 |
| 时间 Chip | 暖棕描边和文字、最小高度 44；Hover/Focus 显示删除按钮，同时保留其 40×40 位置 |
| ChoiceChip | 星期、月日选择沿用 Material 3 主题；选中语义与普通 Chip 由框架处理 |
| 日程列表 | `TriggerRow` 用细分隔线；名称为主、时间为辅；完成后名称变 sage，并加完成图标 |
| Card | 当前无全局 `CardTheme`；恢复提示、错误卡和 Toast 使用局部 Material 容器，分别服务对应反馈用途 |
| Dialog | 共享纸色、暖棕厚边框、小圆角；编辑内容上方为标题和说明，操作在内容下方；确认弹层沿用 `AlertDialog` |
| 日期与时间 | 暖棕选择、米色底；时间盘选中数字同时加粗、放大和下划线，避免只靠颜色 |
| Toast | 应用级右下方叠放，最多 3 条；纸白底、状态图标、正文、关闭按钮；成功 4 秒，失败/警告 6 秒 |

现状：业务界面复用 Flutter 标准组件和主题，尚无统一的 Button/Input/Card 包装组件；组件一致性主要靠 `NotebookTheme`、`PaperPage`、`PageHeading` 和局部共享样式维持。

建议：新增纸面组件直接复用主题和现有页面组件，房间入口复用房间样式。Toast 成功与 sage 可在后续归并为统一语义角色；删除确认目前仍用暖棕 FilledButton，若增加危险操作样式，应同时明确图标、文字与确认流程。

## 4. 建立视觉层级

1. **环境层**：房间插画与时间建立陪伴感，固定入口贴近窗口边缘，保留中央场景。
2. **任务层**：本子展开后，房间被遮罩和模糊；纸面成为主要阅读区域，暖棕封面与书签标识导航。
3. **页面层**：10 号英文眉题 → 28 号宋体标题 → 12 号副标题 → 留白和分隔线 → 正文列表。
4. **条目层**：日程名称使用 ink，时间与投递信息使用 muted，说明位于名称下方；完成图标与 sage 表达事实。
5. **操作层**：主要提交使用实心按钮，单条辅助操作用描边，返回/取消/导航用文字；选择数量与批量操作集中展示。
6. **反馈层**：读取进度放在内容附近，错误保留在原页面并提供重试，短暂结果用 Toast 补充。

日历选中日期使用实心暖棕，今天用描边，有安排用小点；小点始终保留布局高度，避免数字跳动。空状态采用简短文字与留白，不能在尚未取得数据时误显示「全部完成」。投递状态与确认状态分别显示，「已提醒」不等同于「已完成」。

## 5. 完善交互状态

| 状态 | 当前实现 | 后续统一要求（建议） |
| --- | --- | --- |
| Normal | 纸面组件使用暖棕主题，房间固定入口使用米白底暖棕字 | 同用途组件复用同一角色与尺寸 |
| Hover | 普通 Button/InkWell 使用框架反馈；时间 Chip 覆盖暖棕 alpha .06，并显示删除入口 | 保持轻微反馈，显示辅助操作时保留空间 |
| Pressed | 普通控件继承 Material 3 状态覆盖层/水波纹；房间本子热区显式透明 overlay | 不把框架默认反馈记为已有自定义令牌；场景热区保留 Tooltip 与焦点反馈 |
| Focus | 输入框暖棕 2 宽描边；时间 Chip 描边增粗；房间本子热区显示浅暖色 .8 宽边界 | 全程可辨认键盘焦点，不仅依靠悬停显示关键操作 |
| Selected | 标签切换底色，日期实心填充；时间字段换底色，盘面数字放大/加粗/下划线 | 选择状态具备颜色以外的区分和 selected 语义 |
| Disabled | 普通按钮 `onPressed: null` 使用框架禁用态；添加日程有专用禁用配色与原因 Tooltip | 区分连接不可用、提交中、只读；避免仅减透明度表达原因 |
| Loading | 列表/设置显示线性进度，日期详情/服务启动显示圆形进度；保存文字切换为「保存中…」 | 提交期间阻止重复操作，保留内容与上下文 |
| Error | 字段校验、页内错误、重试入口与失败 Toast；启动错误提供重试/退出 | 关键错误持续可见，说明影响与恢复方式 |
| Success / Warning | 完成图标、sage、成功/警告 Toast；操作完成但刷新失败可分别反馈 | 短暂反馈补充持久状态，不能替代最终结果展示 |
| Empty / Stale / Read-only | 有专用空文案；部分视图标注「上次读取」；通知点击只读定位，历史详情限制编辑 | 空、失败、旧结果和只读分别说明，避免混淆 |

编辑与设置弹窗防止点击遮罩直接丢失草稿；关闭/Esc 经草稿检查，未保存修改需确认，忙碌期间相关退出操作受限。日程本支持 Esc、关闭按钮和点击遮罩关闭，编辑草稿同样受守卫约束；合上后焦点回到打开入口。普通详情和管理弹窗沿用各自路由关闭行为，不假定全部弹窗具有相同守卫。

## 6. 实际使用环境

### 6.1 窗口、响应式与 DPI

- 当前面向 Windows 可调整大小的桌面窗口，原生初始尺寸为 1280×800，创建时按目标显示器 DPI 缩放；客户区大小与外框尺寸不同。未发现显式最小窗口尺寸约束。
- 房间原图基准 1672×941，使用 `BoxFit.cover` 居中裁切；背景、本子和猫咪热区共用变换，点击区与可见图像同步。图片热区被裁出视口时仍有右上角固定入口；猫咪悬停/聚焦气泡限制在视口内，点击进入 AI 标签，关闭后返回原入口焦点。
- 窗口内容宽度小于 650 时，时钟顶部从 26 下移到 80；小于 800 时，恢复提示底部从 24 上移到 84，减少与固定入口重叠。
- 本子外框宽度为 `clamp(窗口内容宽度−64, 260, 1120)`，高度为 `clamp(窗口内容高度−108, 160, 720)`；日程双页内容宽度不足 840，或 14 号字缩放后超过 20 时，使用 840 宽横向滚动，纸页各自纵向滚动。AI 标签在同一断点使用单栏导航，不进入双页横向兜底。四标签顺序固定为今天、历史待确认、日历、AI 对话；标签区域可横向访问，关闭按钮始终固定。
- 时间面板宽度至少 530 且缩放后的 14 号字小于 20 时左右排列，否则上下排列；组合日期/时间选择保留最少 800 宽，大字模式最少 1000 宽，支持横向滚动。
- 编辑弹窗最大宽 480，纯时间弹窗最大宽 620，组合选择弹窗最大宽 1100；管理列表内容期望尺寸 440×350，设置内容宽 480。它们与框架屏幕约束共同作用，并非全局统一弹窗宽度。
- 原生窗口处理 `WM_DPICHANGED` 与 `WM_SIZE`；Flutter 按逻辑单位布局。系统 DPI 和系统文字缩放分别影响窗口/渲染与文本，不能互相替代验收。

建议验收组合：1280×800、1440×900 和 640×480 客户区；100%、125%、150%、200% DPI；1.0、1.6、2.0 文字缩放；跨显示器移动。检查长标题、长错误、两页滚动、弹窗底部操作、标签和房间入口重叠。当前局部断点与滚动兜底不代表任意极小窗口均已适配，尚未提供移动端重排。

### 6.2 动画一致性

| 动效 | 当前参数与行为 |
| --- | --- |
| 房间时段切换 | 新图预解码后 550 ms 交叉淡入；失败保留上一张 |
| 本子展开 / 合上 | 1100 / 850 ms，`easeInOutCubic`；从入口移动、缩放、旋转到展开位置 |
| 本子内容与遮罩 | 纸面内容在控制器最后 25% 淡入；模糊与遮罩随开合进度变化 |
| 减少动画 | 房间切换时长置零；本子直接到展开/关闭状态 |
| 普通控件与 Dialog | 使用框架默认状态反馈与路由过渡，尚无共享时长/曲线令牌 |

本子开合期间阻止页面点击和内容焦点进入。环境秒级刷新只驱动时钟，跨时段才切换背景。Toast 当前直接加入/移除，没有单独的进退场动画。建议将慢速场景动作与短促控件反馈分别定义，继续遵循系统减少动画设置，避免把所有交互套用 1100 ms。

### 6.3 可访问性与可读性

- 已有支持：背景 `ExcludeSemantics`；本子 `FocusScope`/`BlockSemantics`；日历、时间盘提供 selected 与标签语义；复选框命名；图标操作提供 Tooltip；Toast 使用 liveRegion；详情支持选择复制。
- 时间选择支持直接输入、盘面点击/拖动、滚轮逐格调整与方向键；小时输入可转到分钟，时间标签支持 Delete 删除，关键关闭路径支持 Esc。
- 当前点击目标并未全部统一：添加入口 44×44，日期和盘面数字 40×40，Toast 关闭按钮最小 36×36；封面底部部分文字操作使用 shrinkWrap，场景本子热区随图片裁切。
- 以不透明纯色计算，ink/paper 对比度约 **8.19:1**，muted/paper **3.87:1**，sage/paper **4.52:1**，cover/paper **4.04:1**。暖棕按钮的米色文字同样约 4.04:1；实际渐变与半透明场景仍需单独检查。
- 建议将普通文字对比度至少 4.5:1 作为后续验收目标，优先改善既有小字号 muted 文本与暖棕按钮文字；通用操作目标尽量达到 44×44，保留键盘和语义替代路径。
- 当前没有独立高对比度主题、完整屏幕阅读器验收或跨 DPI 实测结论。系统字体回退和截图中的缺字风险需在正式 Windows 环境检查；已有截图不代替这类验证。
