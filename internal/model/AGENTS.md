# 业务模型

定义日程、提醒及各层共用的业务数据类型。

- `schedule.go`：单次与周期日程、启停/取消/删除状态、结构校验及共享未找到错误。
- `notification.go`：提醒计划时间、投递状态、用户确认时间、分页位置与确认错误。
- `query_option.go`：日程查询筛选、分页和软删除可见性选项。
- `time.go`：固定 UTC+8 北京时间工具。

工程约束：持久化业务模型使用 `Schedule` 和 `Notification`，日程本是界面展示形式。日程单次/周期规则二选一；提醒投递状态与用户确认时间分别保存。查询选项字段通过只读方法暴露，必填 ID 单独传入。
