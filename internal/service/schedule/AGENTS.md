# 日程服务

- `schedule.go`：日程查询端口、事实与规则投影、日期/月历及分页。
- `schedule_change.go`：正式规则写入、校验、幂等摘要和存储提交。
- `schedule_delete.go`：正式版本删除与独立只读回执查询，摘要包含删除操作、目标和 expectedRevision；同键不同请求拒绝，回执优先于版本和删除状态判断，未命中核对不执行业务。
- `schedule_mutation.go`：日程正式写入结果的只读变更摘要。
- `rules.go`：周期规则解析、下一次触发计算和投影转换。
- `next_notify_test.go`、`schedule_mutation_test.go`：规则与变更摘要测试。

# 约束

- 依赖日程存储端口和共享 model，不依赖 App、API 或具体存储实现。
- 新建和更新校验后通过同一事务提交规则与首条提醒；查询事实与投影使用存储快照。
- 周期触发使用固定北京时间，投影按日程与计划时刻去重。
- 五字段周期规则仅支持每天、每周列表、每月列表；下一次触发严格晚于基准，短月按月末处理。新写入单次必须为分钟精度，旧秒级规则仅保留历史事实。
- 创建和更新使用 expectedRevision 与幂等摘要维护正式回执；提交成功后由 App 通知调度器，调度加载失败不撤销已提交规则。
- 日期触发页的 openScheduleCount 在完整事实和投影集合上按日程去重、先统计后分页，不按确认状态过滤。
- 变更摘要只使用事务前后态；名称和说明只记录字段名，幂等重放只描述原回执。
