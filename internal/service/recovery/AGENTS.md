# 恢复服务

- `notification_recovery.go`：恢复轮次、遗漏窗口、历史去重、批次位置和只读进度。
- `recovery_candidates.go`：有界展开日程历史版本。
- `recovery_candidates_test.go`：版本边界、续页和批次上限测试。

# 约束

- 恢复轮次、扫描位置与历史去重由本模块持有；历史写入使用存储端口的批次接口。
- 与投递服务只通过明确操作及值类型交接，不读取或修改其内部任务、attempt、成员及预算。
- 恢复按整分钟触发范围处理，每个历史批次最多补齐 500 条提醒。
- 从可证明版本和已有事实的最早边界扫描，轮次终点固定；暂停区间不生成，未知早期规则不猜测补造，批次间让出 App.operations。
- 当前分钟仍交实时调度，空的亚分钟间隙不新建轮次；调度窗口交接使用截断到分钟的同一时钟值。
- 未有效开始的旧分钟封存后交恢复；连续遗漏将未开始的旧恢复汇总并入新轮，撤销旧身份。已经开始的任务保留成员、预算、身份和对应旧轮次摘要。
- 整理全部完成才开放 recovery 汇总；完整历史、当前未确认和可投递数量分别统计，未知遗漏总数为 null；确认不删除恢复历史。
- Prepare 只做轮次准备和任务交接，RunStep 才提交历史批次；只读查询不推进恢复。
