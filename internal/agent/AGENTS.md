# Agent 应用层

- 持久化故障日志统一包含运行/会话/调用身份、保存阶段、checkpoint 阶段、原始存储错误及收尾重试序号。失败收尾保留实际结果，首次外每五秒最多三次，只重试持久化；耗尽释放内存占用及现有订阅，数据库状态保持真实。退出中的收尾等待及保存受宿主剩余预算约束，迟到工具不能再次结算。

- 模型、摘要和续写恢复复用已提交原请求、结构化输出及统一进度；完整响应统一校验后接纳，只有需要新请求时检查原模型配置。宿主通过 Lifecycle.Shutdown 传入共享退出期限；在途持久化及工具等待受同一期限约束，已提交事实留待恢复。

- 正常长度截断由协调器在全部工具结果配对后新建 continuation 调用；进度模块只生成独立续写消息、用途限定的截断参数反馈及正文投影。统一 max_continue 默认 5，按已有用途标记跨重启计数、包含摘要续写，不占普通轮数；网络故障不转为正常续写，耗尽保留成功调用及输出并明确失败。

- 工具协调器区分一次有效尝试与逻辑最终结果：热读并发/超时、串行互斥、即时超时释放及 token 迟到隔离；暂时错误沿原调用退避和有限重试，只有最终结果提交统一进度。默认并发 3、超时 30 秒、首次外 3 次重试与 5/10/20 秒退避；全批结果完成才继续模型。
- 工具超时逐项结算并重检已返回事实，持久化等待不改变及时结果；正常退出保留仍可重试的逻辑工具和期限，用户取消及会话删除终止后续重试。

- `chat`：会话、运行、同会话原文幂等、原子三会话准入、查询、协作取消、取消只读恢复、订阅及持久化窄端口；运行占用在启动 ready 前重建。
- `completion`：Chat Completions HTTP/SSE 模型适配器，解析真实正文、思考、响应 ID 和原始 usage。
- `tools`：统一工具接口和注册中心，代码内置单条、列表及日期日程查询，以及创建/修改工具；通过正式业务窄端口读写，不直接访问日程表。创建与修改串行调用正式写入，使用空业务 key；修改保留未提交字段并携带 expectedRevision，相对日期按实际解析时北京时间转换。
- `tools` 同时提供唯一危险且串行的 delete_schedule，调用正式版本幂等删除；聊天协调器首次登记生成后台键、持久化后通过 context 注入，参数错误仍保留，重入复用原身份。只读业务回执由 App 独立端口提供，统一进度不生成执行身份或另拼删除 checkpoint。
- 模型协调器持久化同调用的重试预算、次数、退避与结果；适配器区分上游语义错误、有效输出超时和网络中断，SDK 不自行重试。
- 新运行读取持久化的完整有效消息快照，跨轮保留中断内容和独立 user 说明；实际请求按完整 UTF-8 序列化字节统一估算，普通轮数从现有逻辑调用统计并限制。
- 聊天内部统一生成回复接纳、调用开始/结束、工具开始、单项结果、取消/故障补齐进度及历史接续消息；待提交快照与此前消息及工具事实隔离。工具与终态事务回读最新已提交进度和工具事实后应用统一规则，协调器只采用提交后的完整快照；保存失败停止新推进，只收集已返回查询的实际结果后重试持久化，其他在途查询不阻挡收尾。SQLite adapter 保留事务核验与原子保存，不自行生成取消或未确认结果；全部原 ID 配对后的 tool_end 只表达批次完成事实。

应用层不依赖 App、HTTP Handler 或具体 SQLite。正常与开发入口均装配真实服务，无内存聊天产品实现或种子会话。测试仅在上游响应和故障边界注入替身。

- 取消先提交 wait_for_cancel 再停止推进；工具开始与取消共用启动门，保留原尝试期限和实际结果，退避/未开始项由统一进度跳过。取消恢复仅通过 Registry 的 ResultReader 核对 running/retry_wait 的业务回执，实际回执优先；未确认不重执。正常恢复先核对回执，再沿原记录、参数及固定剩余预算重执行，核对命中不扣次。会话删除与活动运行取消意图在同一短事务保存。

- 创建前摘要由协调器按统一配置阈值和完整有效历史触发；固定专用提示、禁用工具，沿原模型重试和共享续写预算。统一进度负责摘要接纳、正文投影及失败历史接续，SQLite 原子保存摘要生效、会话引用和下一普通调用，不更改数据库结构或 HTTP 契约。

- 工具模型侧 content 在统一结果入口按可配置 token 阈值裁剪；原始 output、结果事件和执行状态独立保留，已提交投影沿 checkpoint 直接恢复。工具整批配对后由协调器检查实际预算并触发运行中摘要；摘要期间保留完整有效上下文供失败、取消和重启接续，成功切换后只保留新摘要与真实输入。摘要不计普通轮次，后续普通调用仍核验轮数上限。
