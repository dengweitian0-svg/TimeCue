# 配置管理

- `chat.max_continue` 由 default.yaml 提供默认 5 次，缺省或 0 使用默认值，负数拒绝发布；沿统一配置覆盖、快照和目录监听热更新，由 ChatModels 提供协调器使用。chat_test.go 覆盖默认/覆盖/负数保留旧快照及真实热更新。

- `chat.tool_concurrency`、`tool_timeout_seconds`、`tool_max_retry` 统一管理工具运行参数，默认 3/30/3；并发与超时的 0 使用默认值，显式零重试有效，负数拒绝发布。调度及每次尝试读取当前值，读取失败时保留批次最近有效工具参数，逻辑工具预算首次登记后固定；CurrentConfig 深拷贝工具重试指针。

管理应用元数据、日志、数据库及聊天模型配置。

- `default.yaml`：内嵌默认配置。
- `config.go`：`NewManager` 接受可选数据目录，固定绝对配置路径，合并默认值并发布快照；监听目录覆盖文件新建、删除及原子替换，提供 Close 等待监听退出；解析普通运行路径及 SQLite 特殊数据源。
- `config_test.go`：默认值与覆盖、只读加载、异常保留旧快照、外部原子替换/清空/重建后的监听及路径测试。
- `config_test.go` / `chat_test.go` 的同步非法配置校验先关闭目录监听，再显式加载，分别验证拒绝非法值与快照隔离；热更新用例保留真实目录监听，覆盖清空恢复默认值与后续配置发布。

工程约束：内嵌 `default.yaml` 为运行时只读基线；用户 `config.yaml` 的应用内写入由 Flutter 负责，Go 只读取、校验、合并默认值并监听，不提供修改或恢复默认的写入入口。NewManager 无参调用固定创建时的工作目录；Go 入口显式注入启动参数目录或可执行文件目录。加载与重载使用同一固定配置路径，缺少用户文件时不创建配置文件。配置快照原子替换，不原地修改已发布快照；重载串行化。路径解析不修改快照文本，不改变进程工作目录；`:memory:` / `file:` 原样交存储。日志组件热更新应用 `log.level`，聊天每次读取最新模型与 .env，数据库/日志路径快照变化不切换已打开资源。生命周期所有者在日志关闭前关闭并等待目录监听。

- `chat.go`：chat_model 提供方分组、模型上下文与输出预算及 chat 超时/max_retry 配置；读取固定 data-dir 的最新 .env，按 PROVIDER_MODEL 规则定位密钥，不探测上游。CurrentConfig 深拷贝嵌套模型与指针字段，调用方不能污染已发布快照。缺少 Key 不影响配置加载和本地功能。
- `chat.max_rounds` 配置普通逻辑调用上限，缺省或 0 使用 20，负数拒绝发布；通过现有配置快照与监听统一加载，不新增 run 参数快照。chat_test.go 验证默认值、热更新与非法轮数配置保留旧快照。
- 模型名与 provider 保留原值；密钥定位仅保留大写 ASCII 字母数字，其余字符替换下划线。规范化冲突、空模型身份及负数重试/超时拒绝发布新快照；重载失败保留原有效配置。`chat_test.go` 覆盖冲突、默认 3/120/60、显式零重试、固定数据目录的 .env 新增/替换/清空/删除及配置监听更新。

- `chat.compact_threshold` 统一加载摘要触发比例，default.yaml 默认 0.8，0 恢复默认，允许大于 0 且不超过 1；负数、超范围和非有限数拒绝发布，保留旧快照。ChatModels 提供当前有效值，chat_test.go 覆盖默认、覆盖与非法值。

- `chat.tool_result_max_tokens` 由 default.yaml 默认 8192，0 恢复默认，允许 64 至当前平台 max_int/4，保证省略说明及字节预算可表示。统一加载、校验、快照和目录热更新，由 ChatModels 提供新结果投影阈值；非法更新保留原快照，已提交模型文本不重剪。
