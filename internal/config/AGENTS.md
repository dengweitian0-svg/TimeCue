# 配置管理

管理应用元数据、日志与数据库配置。

- `default.yaml`：内嵌默认配置。
- `config.go`：合并默认值与工作目录的 `config.yaml`，发布配置快照，监听文件变化并更新日志级别。
- `change.go`：修改用户配置、保留已有未知字段、原子写入文件及恢复默认值。
- `config_test.go`：配置加载、监听、写入和恢复测试。

工程约束：内嵌 `default.yaml` 为只读基线，修改/恢复只写工作目录的 `config.yaml`；用户修改保留未知字段。配置快照原子替换，不原地修改已发布快照。当前组件热更新仅应用 `log.level`，数据库路径快照变化不表示连接已切换。
