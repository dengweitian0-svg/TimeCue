# 配置管理

管理应用元数据、日志与数据库配置。

- `default.yaml`：内嵌默认配置。
- `config.go`：`NewManager` 接受可选数据目录，固定绝对配置路径，合并默认值并发布快照；监听目录覆盖文件新建、删除及原子替换，提供 Close 等待监听退出；解析普通运行路径及 SQLite 特殊数据源。
- `config_test.go`：默认值与覆盖、只读加载、异常保留旧快照、外部原子替换/清空/重建后的监听及路径测试。

工程约束：内嵌 `default.yaml` 为只读基线，内容保持不变；用户 `config.yaml` 的应用内写入由 Flutter 负责，Go 只读取、校验、合并默认值并监听，不提供修改或恢复默认的写入入口。NewManager 无参调用固定创建时的工作目录；调用方可显式注入固定数据目录。加载与重载使用同一固定配置路径，缺少用户文件时不创建配置文件。配置快照原子替换，不原地修改已发布快照；重载串行化。路径解析不修改快照文本，不改变进程工作目录；`:memory:` / `file:` 原样交存储。当前组件热更新仅应用 `log.level`，数据库/日志路径快照变化不切换已打开资源。生命周期所有者在日志关闭前关闭并等待目录监听。
